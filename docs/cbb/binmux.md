# binmux CBB 文档（简单件）

## 1. 基本信息
`CBB-UTIL-008` · `binmux` · `util` · 已发布

## 2. 功能与范围
- **功能**：用二进制选择信号从 N 路数据中选通一路输出。
- **不包含**：不做仲裁、不做数据寄存、不做越界自动钳位。
- **典型场景**：配置选择、寄存器堆读出、测试路径选择。

## 3. 端口表
| 端口 | 方向 | 位宽 | 时钟域 | 说明 |
|---|---|---|---|---|
| `sel` | input | `$clog2(N)`（`N=1` 时为 1） | - | 二进制选择，`0` 到 `N-1` 有效 |
| `data` | input | `N x W` | - | 输入数据，`data[i]` 为第 i 路 |
| `data_out` | output | `W` | - | 选中数据；`sel >= N` 时为 0 |
| `vld` | output | 1 | - | `sel < N` |

无时钟、无复位、无 valid-ready。

## 4. 参数表
| 参数 | 类型 | 默认值 | 合法范围 | 说明 |
|---|---|---|---|---|
| `N` | `int` | `4` | `N >= 1` | 输入路数 |
| `W` | `int` | `32` | `W >= 1` | 数据位宽 |

## 5. 使用说明
- **时钟/复位/初始化**：纯组合逻辑，无时钟和复位。
- **延迟/吞吐**：组合延迟；每拍可选通一个数据。
- **反压/握手**：无。

```systemverilog
binmux #(
    .N (4),
    .W (32)
) U_MUX (
    .sel      (sel_bin),
    .data     (mux_data),
    .data_out (mux_out),
    .vld      (mux_vld)
);
```

## 6. 限制
- `N` 不是 2 的幂时存在越界编码；`sel >= N` 输出 `data_out=0`、`vld=0`。
- 调用方必须检查 `vld`，不能直接用 `sel` 索引下游存储。
