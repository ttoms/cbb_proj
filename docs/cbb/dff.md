# dff CBB 文档（简单件）

## 1. 基本信息
`CBB-BASIC-001` · `dff` · `basic` · 已发布

## 2. 功能与范围
- **功能**：带显式 `en` 的无复位数据通路寄存器。
- **不包含**：不提供复位；不用于状态机、配置、计数器、指针、valid/ready 等控制类寄存器。
- **典型场景**：流水线数据、FIFO 存储体、宽总线打拍。

## 3. 端口表
| 端口 | 方向 | 位宽 | 时钟域 | 说明 |
|---|---|---|---|---|
| `clk` | input | 1 | - | 时钟 |
| `en` | input | 1 | `clk` | 写使能；`en=1` 时 `q <= d`，否则保持 |
| `d` | input | `W` | `clk` | 数据输入 |
| `q` | output | `W` | `clk` | 数据输出 |

无 valid-ready 接口。

## 4. 参数表
| 参数 | 类型 | 默认值 | 合法范围 | 说明 |
|---|---|---|---|---|
| `W` | `int` | `32` | `W >= 1` | 数据位宽 |

## 5. 使用说明
- **时钟/复位/初始化**：仅 `clk` 上升沿；无复位，`q` 在首次 `en=1` 前为不确定值。
- **延迟/吞吐**：`en=1` 时 1 拍；`en=0` 时保持；每拍可写入 1 个数据。
- **反压/握手**：无内建反压，上游通过 `en` 控制写入。

```systemverilog
dff #(
    .W (DATA_W)
) U_DATA (
    .clk (clk),
    .en  (data_en),
    .d   (data_d),
    .q   (data_q)
);
```

## 6. 限制
- `en` 必须连接明确条件，禁止悬空。
- 无复位意味着上电后内容不确定，不能作为控制状态使用；需要复位时改用 `dffr`。
- 仅用于数据通路；存储体大深度时应改用专用 SRAM。
