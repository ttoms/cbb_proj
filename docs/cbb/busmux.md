# busmux CBB 文档（简单件）

## 1. 基本信息
`CBB-UTIL-007` · `busmux` · `util` · 已发布

## 2. 功能与范围
- **功能**：用独热选择信号从 N 路数据中选通一路输出。
- **不包含**：不做仲裁、不做数据寄存、不做多热 OR / 优先级合并。
- **典型场景**：独热译码后的数据选通、寄存器堆读出、测试路径选择。

## 3. 端口表
| 端口 | 方向 | 位宽 | 时钟域 | 说明 |
|---|---|---|---|---|
| `sel` | input | `N` | - | 独热选择；恰好一位有效才选通 |
| `data` | input | `N x W` | - | 输入数据，`data[i]` 为第 i 路 |
| `data_out` | output | `W` | - | 选中数据；未选中时为 0 |
| `vld` | output | 1 | - | `sel` 恰好一位为 1 |

无时钟、无复位、无 valid-ready。

## 4. 参数表
| 参数 | 类型 | 默认值 | 合法范围 | 说明 |
|---|---|---|---|---|
| `N` | `int` | `4` | `N >= 1` | 输入路数 |
| `W` | `int` | `32` | `W >= 1` | 数据位宽 |

## 5. 使用说明
- **时钟/复位/初始化**：纯组合逻辑，无时钟和复位。
- **延迟/吞吐**：组合延迟；每拍可选通一个数据。
- **反压/握手**：无。

```systemverilog
busmux #(
    .N (4),
    .W (32)
) U_MUX (
    .sel      (sel_ohot),
    .data     (mux_data),
    .data_out (mux_out),
    .vld      (mux_vld)
);
```

## 6. 限制
- 只接受恰好一位独热；全零和多热都输出 `data_out=0`、`vld=0`。
- 需要多热 OR 或优先级选择时，先用 `arbiter_pri` 或 `ohot2bin` 预处理。
