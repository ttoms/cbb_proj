# arbiter_pri CBB 文档（简单件）
## 1. 基本信息
`CBB-ARB-001` · `arbiter_pri` · `arbiter` · 已发布
## 2. 功能与范围
- **功能**：固定优先级仲裁，索引 0 优先级最高。
- **不包含**：不做轮询/加权/QoS、不做授权寄存、不做背压。
- **典型场景**：固定优先级中断、简单请求合并、测试平台选通。
## 3. 端口表
| 端口 | 方向 | 位宽 | 时钟域 | 说明 |
|---|---|---|---|---|
| `req` | input | `N` | - | 请求位图 |
| `gnt` | output | `N` | - | 独热授权 |
| `gnt_vld` | output | 1 | - | 至少一个请求 |

无时钟、无 valid-ready。
## 4. 参数表
| 参数 | 类型 | 默认值 | 合法范围 | 说明 |
|---|---|---|---|---|
| `N` | `int` | `4` | `N >= 1` | 请求路数 |
## 5. 使用说明
- **时钟/复位/初始化**：纯组合逻辑，无时钟和复位。
- **延迟/吞吐**：组合延迟；每拍最多一个授权。
- **反压/握手**：无；授权方需自行保证被授权请求仍有效。

```systemverilog
arbiter_pri #(
    .N (4)
) U_ARB (
    .req     (req),
    .gnt     (gnt),
    .gnt_vld (gnt_vld)
);
```
## 6. 限制
- 低索引持续请求会饿死高索引，固定优先级语义如此。
- 需要公平性时改用后续的 `arbiter_rr` / `arbiter_wrr`。
