## 2. 功能与范围 [M]
- **功能**：最近最少使用（LRU）仲裁，优先授权“距上次授权最久”的请求方。
- **不包含**：不做加权、不做 QoS、不做授权寄存、不做背压；不记录请求到达时间。
- **典型场景**：降低饿死风险的多路共享、访问局部性明显的请求源、`arbiter_wrapper` 的 `ARB_LRU` 分支。

## 3. 端口表 [M]
| 端口 | 方向 | 位宽 | 时钟域 | 说明 |
|---|---|---|---|---|
| `clk` | input | 1 | - | 时钟 |
| `rst_n` | input | 1 | `clk` | 异步复位、同步释放，低有效 |
| `upd` | input | 1 | `clk` | 当前 `gnt` 被消费；仅此时更新年龄向量 |
| `req` | input | `N` | `clk` | 请求位图，每路 1 bit |
| `gnt` | output | `N` | `clk` | 独热授权，最多一路有效 |
| `gnt_vld` | output | 1 | `clk` | 有授权时为 1，等价于 `OR(req)` |

无 valid-ready 握手；`gnt` 为组合输出，`req` 在授权周期内必须保持有效。

`upd` 表示“当前 `gnt` 已被下游消费”，仲裁核只在 `gnt_vld & upd` 的时钟沿更新年龄向量。`upd` 必须与消费当前 `gnt` 的那一拍对齐；`upd` 恒为 1 时退化为旧行为。`arbmux` / `strmux` 内部用输出 `vld & rdy` 握手生成该信号。

## 4. 参数表 [M]
| 参数 | 类型 | 默认值 | 合法范围 | 说明 |
|---|---|---|---|---|
| `N` | `int` | `4` | `N >= 1` | 请求路数 |

参数约束：`N >= 1` 由 `arbiter_lru.sva` 检查；派生参数 `IDX_W = (N > 1) ? $clog2(N) : 1`、`AGE_W = (N > 1) ? ($clog2(N) + 1) : 1`。

## 5. 使用说明 [M]
- **时钟/复位**：单时钟；`rst_n` 异步拉低、同步释放，建议由 `rst_sync` 产生。复位清所有年龄，索引 0 最先获得优先权。
- **延迟/吞吐**：`req/age → gnt` 纯组合；每拍最多一个授权，持续请求时 1 次授权/拍。
- **反压**：无。授权方（`arbmux` / `strmux`）负责在未握手时保持请求并处理反压。
- **初始化**：复位后所有 `age=0`，年龄并列时按索引从小到大。
- **upd 语义**：仅在 `gnt_vld & upd` 时更新年龄；`upd=0` 时年龄冻结，授权可重复输出同一路。
- **限制**：年龄计数器饱和后可能并列，退化为低索引优先。

```systemverilog
arbiter_lru #(
    .N (4)
) U_ARB (
    .clk     (clk),
    .rst_n   (rst_n),
    .upd     (upd),
    .req     (req),
    .gnt     (gnt),
    .gnt_vld (gnt_vld)
);
```

## 6. 复位与 CDC [M]
- **复位**：`age` 是控制类寄存器，用 `dffr` 异步复位到 0；无数据通路寄存器。
- **CDC**：无。单时钟模块，所有逻辑同域。

## 7. 限制与注意 [M]
- 只按“上次授权”计算年龄，不记录请求首次到达时间；刚到达的请求如果是第一次参与，年龄为复位后的累计值，可能与实际等待时间不一致。
- 年龄饱和后多个通道可能并列，此时按索引从小到大，严格公平性会退化。
- 请求位图在授权周期内必须稳定；组合撤销请求可能导致 `gnt` 抖动。
- `upd=0` 时年龄冻结，同一路可重复获得授权，直到下游消费。

## 9. 微架构与数据流 [C]
- **模块划分**：单模块，无子模块；组合最大值扫描 + 一个 `dffr` 年龄向量。
- **框图**：

```text
   req[N]                age[N*AGE_W]
     |                        |
     +-----------+------------+
                 |
     +-----------v-----------+
     | 选取 req=1 且 age 最大  |----> gnt[N]（独热）
     | 并列取最小索引           |----> gnt_vld = |req
     +-----------+-----------+
                 |
             gnt_idx
                 |
     +-----------v-----------+
     | 被授权者 age=0          |
     | 其余 age+1（饱和）       |
     +-----------+-----------+
                 |
        +--------v--------+
        | U_AGE dffr      |  en = gnt_vld & upd
        +-----------------+
```

- **数据流**：
  - 选择：遍历 `req`，取 `age` 最大的请求通道；用严格大于比较，天然实现并列时低索引优先。
  - 更新：授权被消费（`gnt_vld & upd`）时，被授权通道 `age=0`，其余通道 `age+1`（到 `AGE_MAX` 饱和）；无授权或 `upd=0` 时年龄保持不变。
  - 输出：`gnt` 由选中索引译码，`gnt_vld=|req`。
- **关键寄存器/存储体**：

| 名称 | 用途 | 复位 | 更新条件（en） |
|---|---|---|---|
| `age[N*AGE_W]` | 每路距上次授权的饱和年龄 | `dffr` 复位 0 | `gnt_vld & upd` |

- **关键设计决策**：用年龄计数而不是完整 LRU 顺序表，面积仅 `N*AGE_W` 位；年龄只在授权时更新，空闲 `en=0` 可门控；饱和处理避免计数器回绕把“最久”变成“最新”。并列时低索引优先，行为确定、便于验证。

## 10. 状态机 [C]
不适用。模块只有年龄向量，没有多步控制序列，也没有状态编码；轮次由授权事件驱动。

## 11. 时序、流水线与 PPA [C]
| 场景 | 延迟 | 吞吐 | 说明 |
|---|---|---|---|
| 正常授权 | 组合（0 拍） | 1 次授权/拍 | `age/req → gnt` 组合路径 |
| 无请求 | 组合 | 0 | 年龄保持不变 |

- **关键路径/流水线**：`age → N 路最大值比较 → 索引译码 → gnt`，深度约 `log2(N)` 的比较树；`N` 大时可在 `arbiter_wrapper` 外层加 `reg_slice` 切分。
- **反压路径**：无。仲裁核不感知下游 ready。
- **面积/功耗**：`N*AGE_W` 个年龄触发器 + `N` 路比较器；无授权时 `en=0`，可被门控。
- **取舍**：年龄计数换较小面积，代价是饱和并列时严格 LRU 退化为索引优先；完整顺序表更精确但面积和搬移逻辑更大。

## 12. 风险与未覆盖项 [C]
- **风险**：长时间持续请求下年龄可能饱和，LRU 精度下降；不记录请求到达顺序，首次请求的年龄不代表真实等待。
- **限制**：单时钟；无背压；无加权/QoS。
- **未覆盖项**：`N > 8`、饱和并列的长时间压力、`req` 为 X/Z、门级仿真与综合时序/面积、形式化验证。
