# debounce CBB 文档（简单件）
## 1. 基本信息
`CBB-BASIC-008` · `debounce` · `basic` · 已发布
## 2. 功能与范围
- **功能**：输入连续稳定 `N` 拍后，输出才跟随输入变化。
- **不包含**：不做输入同步、不做双边沿检测、不做可配置计数方向。
- **典型场景**：按键、机械开关、慢速 GPIO 采样。
## 3. 端口表
| 端口 | 方向 | 位宽 | 时钟域 | 说明 |
|---|---|---|---|---|
| `clk` | input | 1 | - | 时钟 |
| `rst_n` | input | 1 | `clk` | 异步复位、同步释放，低有效 |
| `in` | input | 1 | `clk` | 原始输入 |
| `out` | output | 1 | `clk` | 去抖后的输出 |

无 valid-ready 接口。
## 4. 参数表
| 参数 | 类型 | 默认值 | 合法范围 | 说明 |
|---|---|---|---|---|
| `N` | `int` | `4` | `N >= 1` | 稳定判定的周期数 |
## 5. 使用说明
- **时钟/复位/初始化**：异步复位后输出为 0；复位释放由 `rst_sync` 保证。
- **延迟/吞吐**：输入变化后最多 `N` 拍更新输出；稳定期间无额外延迟。
- **反压/握手**：无。

```systemverilog
debounce #(
    .N (4)
) U_DEB (
    .clk   (clk),
    .rst_n (rst_sync_n),
    .in    (raw_key),
    .out   (clean_key)
);
```
## 6. 限制
- `in` 必须与 `clk` 同步；异步按键需先加 2FF 同步器。
- 短于 `N` 拍的抖动会被拒绝；`N` 越大延迟越大。
