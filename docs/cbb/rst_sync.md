# rst_sync CBB 文档（简单件）
## 1. 基本信息
`CBB-BASIC-003` · `rst_sync` · `basic` · 已发布
## 2. 功能与范围
- **功能**：异步拉低复位、同步释放复位。
- **不包含**：不做复位展宽、不做复位域隔离、不检测复位毛刺。
- **典型场景**：单时钟域内所有 `dffr` 的复位释放。
## 3. 端口表
| 端口 | 方向 | 位宽 | 时钟域 | 说明 |
|---|---|---|---|---|
| `clk` | input | 1 | - | 时钟 |
| `rst_n` | input | 1 | 异步 | 原始异步复位，低有效 |
| `rst_sync_n` | output | 1 | `clk` | 同步释放后的复位，低有效 |

无 valid-ready 接口。
## 4. 参数表
| 参数 | 类型 | 默认值 | 合法范围 | 说明 |
|---|---|---|---|---|
| `STAGES` | `int` | `2` | `STAGES >= 2` | 同步器级数；非法值 elaboration 报错 |
## 5. 使用说明
- **时钟/复位/初始化**：`rst_n` 异步拉低后输出立即为低；释放后经 `STAGES` 个时钟上升沿拉高。
- **延迟/吞吐**：复位释放延迟为 `STAGES` 拍；不影响数据吞吐。
- **反压/握手**：无。

```systemverilog
rst_sync #(
    .STAGES (2)
) U_RST (
    .clk        (clk),
    .rst_n      (rst_n),
    .rst_sync_n (rst_sync_n)
);
```
## 6. 限制
- 只适合单时钟域；跨时钟域复位需单独架构。
- 输出只作为复位释放信号，不能当数据信号使用。
