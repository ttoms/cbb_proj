# bin2ohot CBB 文档（简单件）
## 1. 基本信息
`CBB-UTIL-005` · `bin2ohot` · `util` · 已发布
## 2. 功能与范围
- **功能**：把二进制输入转换为独热输出。
- **不包含**：不做优先级编码、不做多热输入、不做流水线。
- **典型场景**：独热译码、one-hot mux 选择、仲裁器请求展开。
## 3. 端口表
| 端口 | 方向 | 位宽 | 时钟域 | 说明 |
|---|---|---|---|---|
| `bin` | input | `W` | - | 二进制输入 |
| `ohot` | output | `2**W` | - | 独热输出 |

无时钟、无 valid-ready。
## 4. 参数表
| 参数 | 类型 | 默认值 | 合法范围 | 说明 |
|---|---|---|---|---|
| `W` | `int` | `4` | `W >= 1` | 输入位宽；输出宽度为 `2**W` |
## 5. 使用说明
- **时钟/复位/初始化**：纯组合逻辑，无时钟和复位。
- **延迟/吞吐**：组合延迟；每拍可转换一个值。
- **反压/握手**：无。

```systemverilog
bin2ohot #(
    .W (4)
) U_DEC (
    .bin  (sel_bin),
    .ohot (sel_ohot)
);
```
## 6. 限制
- 输出宽度随 `W` 指数增长，建议 `W <= 6`。
- 输入所有编码均合法，输出恰好一位为 1。
