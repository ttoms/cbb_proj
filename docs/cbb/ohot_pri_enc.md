# ohot_pri_enc CBB 文档（简单件）

## 1. 基本信息
`CBB-UTIL-002` · `ohot_pri_enc` · `util` · 已发布

## 2. 功能与范围
- **功能**：优先编码器。在多 bit 请求向量中选出索引最小（优先级最高）的有效位，输出其二进制索引与有效标志。
- **不包含**：不输出独热掩码（用 `arbiter_pri`）、不寄存结果、不做多热合法性检查、不做轮询。
- **典型场景**：固定优先级请求压缩、中断源编号、独热状态转索引（低索引优先）。

## 3. 端口表
| 端口 | 方向 | 位宽 | 时钟域 | 说明 |
|---|---|---|---|---|
| `req` | input | `IN_W` | - | 请求位图，不要求独热 |
| `idx` | output | `$clog2(IN_W)`（`IN_W=1` 时为 1） | - | 最低有效位的索引；`vld=0` 时为 0 |
| `vld` | output | 1 | - | `OR(req)`，至少一位有效 |

无时钟、无复位、无 valid-ready。

## 4. 参数表
| 参数 | 类型 | 默认值 | 合法范围 | 说明 |
|---|---|---|---|---|
| `IN_W` | `int` | `4` | `IN_W >= 1` | 请求位宽 |

## 5. 使用说明
- **时钟/复位/初始化**：纯组合逻辑，无时钟和复位。
- **延迟/吞吐**：组合延迟；每拍可编码一个请求向量。
- **反压/握手**：无；调用方必须用 `vld` 判断 `idx` 是否有效。

```systemverilog
ohot_pri_enc #(
    .IN_W (4)
) U_PRI_ENC (
    .req (req),
    .idx (idx),
    .vld (vld)
);
```

## 6. 限制
- 高索引持续请求会被低索引饿死，固定优先级语义如此；需要公平性改用 `arbiter_rr`。
- `idx` 只在 `vld=1` 时有意义；全零输入返回 `idx=0`。
- 与 `ohot2bin` 的区别：`ohot2bin` 取最高位索引（MSB 优先），本模块取最低位索引。
