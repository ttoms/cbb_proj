# dffr CBB 文档（简单件）

## 1. 基本信息
`CBB-BASIC-002` · `dffr` · `basic` · 已发布

## 2. 功能与范围
- **功能**：带异步复位、常量复位值和显式 `en` 的控制寄存器。
- **不包含**：不做复位同步（由 `rst_sync` 负责）、不提供 valid-ready、不做多时钟域处理。
- **典型场景**：状态机寄存器、配置寄存器、计数器、FIFO 指针。

## 3. 端口表
| 端口 | 方向 | 位宽 | 时钟域 | 说明 |
|---|---|---|---|---|
| `clk` | input | 1 | - | 时钟 |
| `rst_n` | input | 1 | 异步 | 异步复位，低有效 |
| `en` | input | 1 | `clk` | 写使能；`en=1` 时 `q <= d` |
| `d` | input | `W` | `clk` | 数据输入 |
| `q` | output | `W` | `clk` | 数据输出 |

无 valid-ready 接口。

## 4. 参数表
| 参数 | 类型 | 默认值 | 合法范围 | 说明 |
|---|---|---|---|---|
| `W` | `int` | `32` | `W >= 1` | 数据位宽 |
| `RESET_VAL` | `logic [W-1:0]` | `'0` | 任意常量 | 复位值 |

## 5. 使用说明
- **时钟/复位/初始化**：`rst_n` 低有效、异步拉低立即生效；释放必须由 `rst_sync` 同步后再送入本模块。
- **延迟/吞吐**：`en=1` 时 1 拍写入；`en=0` 时保持。
- **反压/握手**：无内建反压，上游通过 `en` 控制写入。

```systemverilog
dffr #(
    .W          (DATA_W),
    .RESET_VAL  ('0)
) U_CTRL (
    .clk   (clk),
    .rst_n (rst_n_sync),
    .en    (ctrl_en),
    .d     (nxt_ctrl),
    .q     (ctrl)
);
```

## 6. 限制
- 复位释放不能直接接原始异步复位，必须经 `rst_sync`。
- `RESET_VAL` 必须是常量，禁止动态值。
- 仅用于控制类寄存器；数据通路请用 `dff`，避免复位树开销。
