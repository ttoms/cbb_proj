# ohot2bin CBB 文档（简单件）

## 1. 基本信息
`CBB-UTIL-006` · `ohot2bin` · `util` · 已发布

## 2. 功能与范围
- **功能**：把独热输入编码为二进制索引，并给出有效标志。
- **不包含**：不做独热合法性错误上报、不做多热拒绝、不做流水线寄存。
- **典型场景**：仲裁结果编码、独热状态压缩、中断源编号。

## 3. 端口表
| 端口 | 方向 | 位宽 | 时钟域 | 说明 |
|---|---|---|---|---|
| `ohot` | input | `IN_W` | - | 独热输入 |
| `bin` | output | `$clog2(IN_W)`（`IN_W=1` 时为 1） | - | 最高有效位索引；全零时为 0 |
| `vld` | output | 1 | - | `ohot` 至少一位为 1 |

无时钟、无复位、无 valid-ready。

## 4. 参数表
| 参数 | 类型 | 默认值 | 合法范围 | 说明 |
|---|---|---|---|---|
| `IN_W` | `int` | `4` | `IN_W >= 1` | 独热输入位宽 |

## 5. 使用说明
- **时钟/复位/初始化**：纯组合逻辑，无时钟和复位。
- **延迟/吞吐**：组合延迟；每拍可转换一个值。
- **反压/握手**：无。

```systemverilog
ohot2bin #(
    .IN_W (4)
) U_ENC (
    .ohot (gnt_ohot),
    .bin  (gnt_bin),
    .vld  (gnt_vld)
);
```

## 6. 限制
- 多热输入不报错，按最高位索引编码；需要严格校验时外部检查 `$countones(ohot)==1`。
- 全零输入返回 `bin=0, vld=0`，调用方必须用 `vld` 判断结果是否有效。
