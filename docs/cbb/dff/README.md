## 2. 功能与范围

- **功能**：带显式 `en` 的无复位数据通路寄存器。
- **不包含**：不提供复位，不用于状态机、配置、计数器、指针、valid/ready 等控制类寄存器。
- **典型场景**：流水线数据、FIFO 存储体、宽总线打拍。

## 3. 端口表

| 端口 | 方向 | 位宽 | 时钟域 | 说明 |
|---|---|---|---|---|
| `clk` | input | 1 | - | 时钟 |
| `en` | input | 1 | `clk` | 写使能；`en=1` 时 `q <= d`，否则保持 |
| `d` | input | `W` | `clk` | 数据输入 |
| `q` | output | `W` | `clk` | 数据输出 |

本模块无 valid-ready 接口。

## 4. 参数表

| 参数 | 类型 | 默认值 | 合法范围 | 说明 |
|---|---|---|---|---|
| `W` | `int` | `32` | `W >= 1` | 数据位宽 |

## 5. 使用说明

- **时钟/复位**：仅使用 `clk` 上升沿；无复位端口。
- **延迟**：`en=1` 时 1 拍；`en=0` 时输出保持。
- **吞吐**：每拍可写入 1 个数据。
- **反压**：无内建反压；上游必须通过 `en` 控制写入。
- **初始化**：无复位，`q` 在首次 `en=1` 前为不确定值；上游必须保证首次写入前数据有效。
- **限制**：禁止用于控制/状态寄存器；跨时钟域需使用 CDC CBB。

例化示例：

```systemverilog
dff #(
    .W (DATA_W)
) U_DATA (
    .clk (clk    ),
    .en  (data_en),
    .d   (data_d ),
    .q   (data_q )
);
```

## 6. 复位与 CDC

- **复位**：无复位，属于数据通路寄存器，避免复位树开销。
- **CDC**：不处理跨时钟域；单 bit 用 `cdc_2ff`，多 bit 用格雷码/握手/异步 FIFO。

## 7. 限制与注意

- `en` 必须连接明确条件，禁止悬空。
- 无复位意味着上电后内容不确定，不能作为控制状态使用。
- 需要复位的场景请改用 `dffr`。
